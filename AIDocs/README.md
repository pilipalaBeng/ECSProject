## 律法 / 事实 / 数值：三分而治

改动前先判断你动的是哪一类，**它们的变更程序完全不同**：

| 类别 | 文件 | 变更频率 | 改动程序 |
|------|------|----------|----------|
| **律法** | `00-宪法/CONSTITUTION.md`、`01-治理/CONSTRAINTS.md` | 季度 | 必须走 ADR（`[宪法修订]` / `[约束变更]`），版本号按语义递增 |
| **事实** | `01-治理/工程事实.md` | 周 | 直接改，无需 ADR，留一行变更记录 |
| **数值** | `01-治理/数值预算表.md` | 天 | 直接改，无需 ADR，但必须同步 rationale / 验证路径 |

**为什么分**：把版本号放进宪法，升级一次 Entities 就得改宪法，修订程序会被架空（ADR-0007）。

## 文档契约（每份文档必须带）

| 字段 | 说明 |
|------|------|
| 版本 | 新增/收紧规则 MINOR，删除或反转 MAJOR，措辞 PATCH |
| 批准日期 / 最近修订 | 宪法与 CONSTRAINTS 必带，其余可选 |
| 主源声明 | 若本文件是某类信息的主源，写明；若为引用，写「主源在 X」 |
| 加载级别 | L0 常驻 / L1 按需 / L2 参考 |

引用别的文件时**指向条目编号，不复制数字**。
