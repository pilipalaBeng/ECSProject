# 术语表

> **L2 参考层**。项目特有术语的统一口径。文档与代码命名出现分歧时，以本表为准。

## 玩法层

| 术语 | 英文/代号 | 定义 |
|------|-----------|------|
| 字潮 | WordTide | 大规模低复杂度敌方单位群（同屏 5,000-15,000），聚合渲染，不可单独击杀 |
| 字牌 | WordCard | 玩家持有的字武器，战斗中以切换方式使用，带五行属性 |
| 字库 | WordDeck | 玩家当前局内持有的字牌集合，肉鸽构筑的对象 |
| 相克 | WuxingCounter | 五行克制关系，唯一伤害倍率来源（×3.0 / ×1.0 / ×0.4） |
| 逆属性 | Countered | 玩家当前字牌被敌方字潮克制，倍率 ×0.4 |
| 合成 / 叠字 | Merge | 同字合并升阶（火+火=炎，炎+火=焱），build 的升级路径 |
| 碎裂 | StrokeBurst | 击杀表现：汉字拆解成笔画飞散的预烘焙序列帧（6 帧） |
| 波次 | Wave | 单波战斗，30-60 s，割草释放期 |
| 构筑期 | DraftPhase | 波间 20-40 s 的三选一决策期 |
| 千人斩 | ThousandSlay | 连击阈值触发的全屏清场大招（500 / 1000 / 5000） |
| 战役关 | CampaignStage | 单局内的大关卡，对应一场三国战役 |
| 名将 | Warlord | Boss 单位，Hybrid 表现，同屏 1-8 个 |
| 阿斗模式 | A'Dou Mode | 护送阿斗的高难度模式，**默认关闭**（C7.5） |

## 技术层

| 术语 | 英文/代号 | 定义 |
|------|-----------|------|
| 三层 LOD | LOD3 | 近场（独立）/ 中景（聚合）/ 远潮（密度场）的分层表现方案 |
| 聚合字块 | Cluster | 中景渲染单位，一个块代表一批同类实体，显示为"兵 ×327" |
| 墨潮 | InkTide | 远潮层纯 shader 的密度场视觉，零实体 |
| 序列帧 | Flipbook / Sprite Sheet | 预烘焙的逐帧动画图集，本项目唯一的美术资产形态 |
| 图集烘焙 | Atlas Bake | Editor 阶段把字形 + 变形帧烘焙成 sprite sheet 的过程 |
| 空间分区 | SpatialGrid | 16×16 网格，用于把邻近查询从 O(n²) 降到 O(n·k) |
| 热路径 | HotPath | 每帧在万级实体上运行的代码，禁止堆分配 |
| Hybrid 单位 | Hybrid | Entity 跑逻辑 + GameObject 跑表现的混合单位（名将层） |
| Burst | Burst | Unity 的 C# → 原生代码编译器，ECS 性能来源 |
| 批次上限 | BatchCap | `DrawMeshInstanced` 单次 1,023 实例硬限（C4.3） |
