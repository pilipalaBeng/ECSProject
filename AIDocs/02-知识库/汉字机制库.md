## 1. 五行属性体系

**这是唯一的伤害规则来源**（宪法 §2.5）。所有字必须归属五行之一。

### 1.1 相克关系

```
        木  ──克──▶  土
        ▲             │
        │             ▼
        水  ◀──克──  火  ──克──▶  金  ──克──▶  木
```

| 关系 | 倍率 | 状态 |
|------|------|------|
| 相克（我克敌） | **×3.0** | [PLACEHOLDER] |
| 被克（敌克我） | **×0.4** | [PLACEHOLDER] |
| 中性 | ×1.0 | 基准 |

**倍率 rationale**：×2 时玩家感觉"切对了个寂寞"，×4 会让非相克变成惩罚性体验。3.0 是"我做对了"能被明确感知的阈值。被克 0.4 而非 0——归零会造成"完全打不动"的挫败，违反 pillar 3「对的时候要碾压，错的时候只是低效」。

### 1.2 五行字库（初版草案）

| 五行 | 兵种字 | 意象 |
|------|--------|------|
| **木** | 巾、徒、卒、林、森、枝、寨、粮、帆 | 乌合、粮草、战船、营寨 |
| **火** | 炎、焱、灼、炬、营、焚 | 火攻、燃烧 |
| **土** | 城、垒、壑、坤、壁、屯 | 坚壁、城防、拒守 |
| **金** | 戟、铁、锋、鑫、甲、骑（西凉铁骑） | 精锐、重甲、铁器 |
| **水** | 江、涛、淼、淹、雨、浪 | 水军、水攻 |

⚠ 上表为草案，字库最终规模受 C3.1（≤500 字）约束，建议首发 200-350 字。

## 2. 合成树（叠字机制）

汉字部件合成是天然的 build 树——**中文母语者看到"三个火"就知道是焱，先验知识直接省掉教学成本**。这是英文做不到的差异化。

| 合成式 | 结果 | 效果方向 | 状态 |
|--------|------|----------|------|
| 火 + 火 | 炎 | 伤害 ↑ | [PLACEHOLDER] |
| 炎 + 火 | 焱 | 伤害 ↑↑ / 攻速 ↓ | [PLACEHOLDER] |
| 木 + 木 | 林 | 范围 ↑ | [PLACEHOLDER] |
| 林 + 木 | 森 | 范围 ↑↑ / 单体伤害 ↓ | [PLACEHOLDER] |
| 金 ×3 | 鑫 | — | [PLACEHOLDER] |
| 水 ×3 | 淼 | — | [PLACEHOLDER] |
| 石 ×3 | 磊 | — | [PLACEHOLDER] |
| 日 + 月 | 明 | — | [PLACEHOLDER] |

**合成的方向性设计原则**：每次合成必须是**取舍**，不是纯数值膨胀。
例：焱 = 伤害 ×2.2 / 攻速 ×0.7（[PLACEHOLDER]）。纯增益的合成会让 build 收敛到唯一解，肉鸽就废了。

**技术约束**：合成出的字可能是生僻字（焱/淼/鑫/磊），必须确认 TMP 字体覆盖，缺字走 fallback 字体链（CONSTRAINTS C3.4）。

## 3. 战役 → 相克映射

**宪法 §2.6**：每关的正确打法 = 史实胜负手。

| 关 | 战役 | 敌方字潮属性 | 历史解（玩家应持的字） | 机制化表达 |
|----|------|--------------|------------------------|------------|
| 1 | 黄巾之乱 | 木：巾 / 徒 / 卒 | 金 | 官军铁器破乌合之众 |
| 2 | 虎牢关 | 金：戟 / 铁 / 骑（西凉铁骑） | 火 | 火克金 |
| 3 | 官渡 | 木：粮 / 车 / 寨 | 火 | **火烧乌巢** |
| 4 | 赤壁 | 木 + 金：船 / 帆 / 锁（连环船） | 火 | **火攻连环船** — 一击点燃整条链 |
| 5 | **长坂坡** | 全属性曹军潮，量最大 | 靠切换，不靠单字 | 十万大军，纯割草，全局高潮 |
| 6 | 水淹七军 | 火：炬 / 营 / 炎 | 水 | **水克火** |
| 7 | 五丈原 | 土：垒 / 壑 / 营（司马懿坚壁） | 木 | **木克土** |

**关卡节奏逻辑**：1-4 关教学相克（每关只压一种属性），第 5 关把所有规则同时压过来，6-7 关回到单属性但强度更高。
