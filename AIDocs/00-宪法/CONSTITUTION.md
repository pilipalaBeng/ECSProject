## 元规则 · 本文件的读法

### 1. 规范关键词（RFC 2119 口径）

| 词 | 含义 | 违反后果 |
|----|------|----------|
| **必须 / MUST** | 绝对要求 | 违反即 Bug，必须修 |
| **不得 / MUST NOT** | 绝对禁止 | 同上 |
| **应当 / SHOULD** | 推荐做法 | 可以有正当理由偏离，但必须在代码注释或 ADR 里写明理由 |
| **可以 / MAY** | 真正可选 | 无需说明理由 |

未标关键词的句子是背景说明，不是规范。

### 2. 冲突裁决序

当本文件内部或跨文件出现冲突时，**按顺序取高者**：

```
§2 设计红线（玩法灵魂）
  ↓
§3 架构铁律（工程底线）
  ↓
CONSTRAINTS 硬不变量（C1-C5 / C7）
  ↓
数值预算表 / 工程事实
  ↓
ADR、知识库、团队惯例
```

**含义**：性能与手感冲突时，先在架构层找技术方案，不得直接削玩法。只有当架构层已穷尽方案、且硬不变量不可让时，才允许回头质疑设计红线——且必须走 ADR，写明「架构层已尝试过哪些方案」。

### 3. 本文件存什么、不存什么

| 存（低频、律法） | 不存（外置） |
|------------------|--------------|
| 设计红线、架构铁律、AI 行为约束、质量门、修订程序 | 引擎与包的**版本号** → `01-治理/工程事实.md` |
| 项目不可变身份（题材、主角、精神原型、Fun Hypothesis） | 代码路径、命名空间、仓库 handle、进度 → 同上 |
| 未定项清单（§9） | 可调数值、`[PLACEHOLDER]` → `01-治理/数值预算表.md` |

**理由**：版本号与路径以周为单位变化，律法以季度为单位变化。混在一起会导致「升级一次 Entities 就要改宪法」，修订程序被架空，宪法反而失真。**事实变了改 manifest，宪法版本号不动。**

## 2. 第一条 · 设计红线（玩法不可协商）

这些是游戏的「灵魂条款」。任何需求、重构、优化都不得触碰：

1. **汉字是机制，不是皮肤。**
   文字必须承担玩法功能（合成、相克、碎裂）。任何「把文字换成图标也能玩」的设计 = 违宪。
   *检验法*：若某系统把汉字替换成任意符号后体验不变，该系统不合格。

2. **「十万」是数字，不是实体。**
   玩家的「十万大军」感受由累计击杀计数器承担，不由场景对象数承担。
   真实模拟实体存在硬上限（见 CONSTRAINTS C1.1）。**禁止**为了「看起来多」而突破上限。

3. **美术必须程序化生成，字形源唯一。**
   所有字形资产源自同一套 TMP 字体资产 + 程序化变形烘焙。
   **禁止**手绘字卡、**禁止**用 AI 生成美术资产（一致性不可控）。例外需 ADR 记录。

4. **字库规模上限硬封顶。**
   总字库不超过 **500 字**（图集内存约束，见 CONSTRAINTS C2.5）。超出即违宪，不靠「优化图集」绕过。

5. **五行相克是唯一的伤害规则。**
   金木水火土相克倍率是核心伤害来源。**不得**引入第二套并行的伤害体系（如「暴击流」「流血流」独立成派）。
   其他增伤必须表达为对相克结果的乘算修正，不得绕开相克。

6. **战役的历史解 = 游戏的相克解。**
   每关的正确打法必须对应史实胜负手（官渡=火烧乌巢、赤壁=火攻连环船、水淹七军=水克火）。
   设计新关卡必须能回答「历史上这场仗是怎么赢的」。

7. **割草期不得被打断。**
   战斗中禁止弹窗、剧情插入、确认对话框。所有决策发生在波间构筑期。
   *理由*：权力幻想依赖连续释放，打断即破功。

8. **数值必须有 rationale。**
   任何进入代码的数值必须能回答「为什么是这个数」。
   无 rationale 的数值一律标 `[PLACEHOLDER]` 并附验证路径（见 `01-治理/数值预算表.md`），**不得**以「先填个能跑的」为由裸奔。

## 3. 第二条 · 架构铁律（代码不可协商）

详见 `01-治理/开发规则总纲.md`。此处只列不可违反的骨架：

1. **逻辑 / 表现分离**：System 内**禁止**触碰 `GameObject`、`MonoBehaviour`、`Transform`。
   逻辑跑 ECS，表现跑渲染层，两者只通过数据 buffer 通信。

2. **热路径零堆分配**：`OnUpdate` / `IJobEntity` 内禁止 `new`、禁止闭包捕获、禁止 LINQ、禁止 `string` 拼接。
   违反者 Burst 编译不过或 GC 爆掉——两者都是事故。

3. **邻近查询必须走空间分区**：伤害范围判定、碰撞检测一律走网格空间分区。
   **禁止** O(n²) 全量遍历。

4. **UI 不进 ECS**：HUD、波间构筑界面走 UI Toolkit，不与 Entity 双向绑定。
   战场文字不在 UI 层，走 instanced 渲染。

5. **图集必须预烘焙**：序列帧 sprite sheet 在 Editor 阶段烘焙成资产。
   **禁止**运行时动态生成图集（会卡死）。

6. **Burst 兼容**：`IComponentData` 内**禁止** managed 类型（class / string / 数组 / 委托）。
   需要字符串的地方存索引，查表。

7. **规模常量集中**：实体上限、LOD 分界距离、批次上限等一律集中在配置资产。
   **禁止**散落在各 System 里的魔数。

8. **程序集单向依赖**：`Core ← Gameplay ← Presentation`，`Editor` 仅引用 Core + Gameplay。反向引用即违规。

## 4. 第三条 · AI 代理行为约束

AI 编码代理在本仓库内必须遵守：

1. **先规划，后动手**：跨 3 个以上文件 / 涉及架构 / 涉及数值的任务，必须先出方案，用户确认后再实施。
2. **上下文分层加载**：
   - **L0 常驻**：本宪法 + `AGENTS.md` + `01-治理/CONSTRAINTS.md`
   - **L1 按需**：`01-治理/*`、ADR
   - **L2 参考**：`02-知识库/*`、规格细案
   不得一次性把 L2 全灌进上下文。
3. **性能类改动必须实测**：声称「优化了」必须给出实测帧率与实体数（如「12000 实体 / 60fps / Burst on」）。
   **禁止**凭代码观感断言性能。
4. **改动范围最小化**：只改达成目标所需的文件。禁止「顺手重构」无关代码。
5. **阶段汇报**：预计 >10 次工具调用的长任务，必须阶段性汇报进度。
6. **积分/成本前置**：涉及 AI 生成资产等消耗积分的操作，动手前先估算并告知。
7. **不顺手删文件**：删除、对外推送、发布类操作必须先确认。
8. **不编造事实**：技术细节不确定时写「待确认/待实测」，**禁止**编造 API、版本号、性能数字。
9. **区分律法与事实**：改 `工程事实.md` 与 `数值预算表.md` 无需走修订程序；改本宪法与 CONSTRAINTS 必须走。

## 5. 第四条 · 质量门（Definition of Done）

任一改动声称「完成」，必须同时满足：

- [ ] 仅改动预期目录，未越过程序集边界
- [ ] Play 模式可跑通：Boot → 目标流程，Console **无 error**
- [ ] 新增 Prefab / SO / 场景引用无 Missing
- [ ] 热路径无新增堆分配
- [ ] 数值改动已同步到 `数值预算表.md`，且带 rationale 或 `[PLACEHOLDER]`（含验证路径）
- [ ] **性能门**：目标实体规模下帧率达标（见 CONSTRAINTS C1.7）
- [ ] 已说明验证方式（怎么复现、看什么现象、达标数字）

**任何一项未满足 → 状态标记为「进行中」，不得报「完成」。**

## 6. 第五条 · 变更与证据

1. **重大决策留档**：影响架构、玩法数值、技术选型的决策必须写 ADR 存入 `01-治理/ADR/`。
2. **规格先行**：新功能先写 Spec（见 `03-规格/模板/`），再写代码。
3. **日志即记忆**：实质性工作完成后，必须追加 `.workbuddy/memory/YYYY-MM-DD.md`。
4. **可回溯**：删除类操作先备份；`.git` 保持可用。
5. **数值变更留痕**：调整任何带 rationale 的数值，必须同步更新其 rationale，不得只改数字。

## 7. 修订程序（Amendment）

1. 提出修订：在 `01-治理/ADR/` 新建 ADR，标题前缀 `[宪法修订]`，写明**原条款 / 新条款 / 理由 / 影响范围**。
2. 按本文件头部「版本语义」递增版本号，并更新「最近修订」日期。
3. 在本文件 §8 追加一行修订记录。
4. **涉及 §1 身份卡与 §2 设计红线的修订，必须由人类开发者明确批准**——AI 代理不得自行修改。
5. 同步检查下游引用：CONSTRAINTS、`工程事实.md`、`数值预算表.md`、`AGENTS.md`、README 是否因本次修订需要连带更新。
